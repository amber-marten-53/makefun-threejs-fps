# Operation Breach (threejs-fps-01)

**Operation Breach** is an original tactical first-person shooter built with Three.js. Two teams compete in short, intense round-based matches on an original map featuring two bomb sites (Alpha and Bravo), buy economies, precision gunplay, and bot AI teammates and opponents.

## Controls
- **Movement**: WASD
- **Look**: Mouse (Pointer Lock)
- **Jump**: Space
- **Crouch**: Ctrl / C
- **Fire**: Left Mouse Button
- **Aim / Secondary**: Right Mouse Button
- **Reload**: R
- **Buy Menu**: B
- **Walk**: Shift

## How to Run
1. Ensure Node.js 22+ is installed.
2. Run the development server:
   ```bash
   node serve.ts
   ```
3. Open `http://localhost:8080` in your browser.
